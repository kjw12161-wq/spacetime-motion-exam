힘과 운동

1-01

힘의 합성

힘은 크기와 방향을 모두 갖는 벡터야. 물체에 여러 힘이 동시에 작용하면, 그 힘들을 더한 합력이 실제 운동을 결정해.

  • 평행사변형법: 두 힘을 두 변으로 하는 평행사변형의 대각선이 합력
  • 삼각형법: 한 벡터의 끝에 다른 벡터를 이어 그리면 시작점~끝점이 합력
  • 합력이 0이면 물체는 힘의 평형 상태 → 정지 또는 등속직선운동
RESULTANT FORCEF = √(F₁² + F₂² + 2F₁F₂cosθ)
TIP

θ=0°면 F=F₁+F₂ (최대), θ=180°면 F=|F₁−F₂| (최소). 두 힘이 이루는 각이 커질수록 합력은 작아져.

1-02

포물선 운동

비스듬히 던진 물체는 수평과 연직 운동이 독립적으로 동시에 일어나며 겹쳐진 결과야.

  • 수평 방향: 등속도 운동
  • 연직 방향: 중력에 의한 등가속도 운동
RANGE / HEIGHTR = v₀²sin2θ / g
H = v₀²sin²θ / 2g
1-03

등속 원운동과 단진동

등속 원운동은 속력은 일정하지만 방향이 계속 바뀌는 운동이야.

  • 구심가속도는 원의 중심 방향
  • 각속도 ω = 2π/T = 2πf
  • 단진동의 복원력은 F=−kx
CENTRIPETAL FORCEF = mv²/r = mrω²SHMF = −kx · T = 2π√(m/k)

CHAPTER

운동의 상대성

2-01

케플러의 법칙과 중력

행성의 운동을 설명하는 케플러 법칙과 만유인력은 천체 운동의 중요한 기반이야.

  • 제1법칙: 타원 궤도
  • 제2법칙: 같은 시간에 같은 면적
  • 만유인력: F∝1/r²
2-02

특수 상대성

모든 관성계에서 진공의 빛의 속력이 일정하다는 가정에서 출발해.

  • 시간 지연
  • 길이 수축
  • 질량-에너지 등가 E=mc²
2-03

일반 상대성

중력을 시공간의 휘어짐과 연결해 설명하는 이론이야.

  • 질량·에너지가 시공간을 휘게 함
  • 강한 중력장에서 시간 지연
  • 휘어진 시공간에서 자연스러운 운동
